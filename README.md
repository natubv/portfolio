# Portfolio — Natalia Ballesteros

Portafolio personal de **Natalia Ballesteros**, diseñadora gráfica digital (Universidad La Salle, 2023–2027) especializada en modelado 3D. Landing one-page responsiva con sistema de diseño maximalista expresivo en rojo y morado (Kepler Std + Neulis Neue, retícula 12 columnas, marcos y figuras SVG propias), que presenta perfil, proyectos 3D / identidad / infografía, educación, experiencia, habilidades y contacto.
